📊 Analisis Butir Soal Psikometrik (Item Analysis)

Menghitung Tingkat Kesukaran (P) dan Daya Pembeda (D) menggunakan metode baku perbandingan kelompok Upper 27% vs Lower 27%.

1. Tingkat Kesukaran (Difficulty Index - P):

P = B / N (B: Siswa benar, N: Total peserta)

Kriteria: P > 0.70 (Mudah), 0.30 - 0.70 (Sedang / Ideal), < 0.30 (Sukar)

2. Daya Beda (Discrimination Index - D):

D = (U - L) / n (Metode Kelompok 27% Atas vs 27% Bawah)

Kriteria: D ≥ 0.40 (Sangat Baik), 0.30-0.39 (Baik), 0.20-0.29 (Cukup), < 0.20 (Jelek)
